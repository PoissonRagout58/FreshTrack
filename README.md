# FreshTrack
Bienvenue, 
# Connexion
Vous devez créer un compte avec une adresse mail et un mot de passe puis ensuite vous avez accès à l'application.
# Fonctionnement 
Vous appuyez sur le bouton scan, vous choississez Ajouter au stock ensuite vous scanner le code bar, vous rentrez les informations comme la quantité, la date de péremption et le produit se rajoute.
Si le produit n'existe pas alors vous devez le remplir vous même.
Dans le futur il sera possible d'améliorer la base de donnée des produits car quand un produit n'existe pas alors vous allez le remplir et ensuite il va être rajouter dans la base de donnée pour la prochaine fois poiur éviter de remplir à chaque fois le produit.
